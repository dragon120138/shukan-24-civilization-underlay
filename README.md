# 书刊24 文明的底色六大文明的古代史与基因密码

> 学术·文明史

## 关于本书

一次祛双重中心主义的文明比较：既不以西方为中心也不以任何单一文明为中心，平视东正教、伊斯兰、犹太、波斯、拉丁天主教与印度六大文明的古代史。每章处理一个文明的底色：地理基座、轴心时代观念突破、政治组织传统，以及这些遗产如何塑造其面对现代性的姿态。焦点在三组永恒问题的不同答案：政教关系、个人与共同体、商业与武力。

## 篇目

- 拉丁天主教文明史料核验索引
- 导论：祛除双重中心主义的文明比较
- 总论：六大文明的底色与多极化秩序的启示
- 《文明的底色》插图需求表
- 结语：文明互鉴共存的史实基础
